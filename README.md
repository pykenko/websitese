# Bina Kasih

Bina Kasih is a web based application developed as a group project to provide an easy way for users to donate.
The application was developed collaboratively as part of a team project.

## Features

- User authentication and authorization
- Responsive web interface
- Dashboard system
- Data management functionality
- Secure backend integration
- Modern UI/UX design

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Flask

### Database
- PostgreSQL

### Other Tools
- Docker
- Git
